# Architecture Modes

System design, clean code principles, and architectural guidance modes.

## Available Modes (4)

| Mode | Description |
|------|-------------|
| `principal-engineer-mode` | Expert-level engineering guidance and architectural decisions |
| `wg-code-alchemist-mode` | Clean Code principles, SOLID, and design patterns expert |
| `sacred-games-architect-mode` | Strategic architecture inspired by complex system design |
| `specification-mode` | Technical specification and design document creation |

## Usage

### Principal Engineer Mode
Best for high-level architectural decisions, system design reviews, and technical leadership guidance.

### Code Alchemist Mode
Focuses on:
- Clean Code principles
- SOLID principles (Single Responsibility, Open/Closed, Liskov Substitution, Interface Segregation, Dependency Inversion)
- Design patterns (Factory, Strategy, Observer, etc.)
- Code refactoring strategies

### Sacred Games Architect Mode
For complex, large-scale system architecture with emphasis on:
- Microservices design
- Event-driven architecture
- Domain-driven design
- System resilience

### Specification Mode
Creates detailed technical specifications including:
- Functional requirements
- Non-functional requirements
- API contracts
- Data models

## Recommended Workflow

1. **Planning Phase**: Use `specification-mode` to document requirements
2. **Design Phase**: Use `principal-engineer-mode` for high-level design
3. **Implementation Phase**: Use `wg-code-alchemist-mode` for clean code practices
4. **Review Phase**: Use `sacred-games-architect-mode` for system-wide review
