# Blockchain Development Modes

Web3, smart contract, and decentralized application development modes.

## Available Modes (3)

| Mode                   | Description                                      |
| ---------------------- | ------------------------------------------------ |
| `solidity-expert-mode` | Solidity smart contract development and security |
| `web3-developer-mode`  | Web3 frontend integration and dApp development   |
| `defi-developer-mode`  | DeFi protocols, AMMs, and financial primitives   |

## Usage

### Solidity Expert Mode

Expertise in:

- Smart contract patterns (Factory, Proxy, Diamond)
- Gas optimization
- Security best practices
- OpenZeppelin contracts
- Upgradeable contracts
- Testing with Foundry/Hardhat

### Web3 Developer Mode

Covers:

- ethers.js and viem
- Wallet integration (MetaMask, WalletConnect)
- Contract interaction
- Event listening
- Transaction handling
- IPFS integration

### DeFi Developer Mode

Includes:

- AMM design (Uniswap, Curve)
- Lending protocols (Aave, Compound)
- Yield strategies
- Flash loans
- Oracle integration (Chainlink)
- Tokenomics

## Security Considerations

All blockchain modes emphasize:

- Reentrancy prevention
- Integer overflow protection
- Access control patterns
- Slippage protection
- Front-running mitigation
- Audit preparation

## Development Workflow

1. **Design**: Plan contract architecture
2. **Implement**: Write Solidity with `solidity-expert-mode`
3. **Test**: Comprehensive testing with Foundry/Hardhat
4. **Audit**: Security review
5. **Deploy**: Mainnet deployment
6. **Integrate**: Frontend with `web3-developer-mode`
