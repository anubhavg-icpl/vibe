# UI/UX Modes

Additional UI/UX and accessibility modes.

## Available Modes (1)

| Mode | Description |
|------|-------------|
| `accessibility-specialist-mode` | WCAG compliance and inclusive design |

## Usage

### Accessibility Specialist Mode
Expertise in making applications accessible to all users:
- Screen reader compatibility
- Keyboard navigation
- Color contrast requirements
- ARIA implementation
- Cognitive accessibility
- Motor accessibility

## WCAG Guidelines

### Level A (Minimum)
- Text alternatives for images
- Keyboard accessible
- No seizure-inducing content
- Navigable structure

### Level AA (Recommended)
- Color contrast 4.5:1
- Resize text 200%
- Multiple ways to find content
- Consistent navigation

### Level AAA (Enhanced)
- Color contrast 7:1
- Sign language for video
- Reading level considerations
- No timing requirements

## Accessibility Checklist

| Category | Requirement |
|----------|-------------|
| Images | Alt text for all images |
| Forms | Labels for all inputs |
| Color | Don't rely on color alone |
| Focus | Visible focus indicators |
| Headings | Proper heading hierarchy |
| Links | Descriptive link text |
| Video | Captions and transcripts |
| Motion | Reduce motion option |
