# AI & Machine Learning Modes

Expert modes for AI/ML development, LLM applications, and MLOps.

## Available Modes (6)

| Mode                          | Description                                            |
| ----------------------------- | ------------------------------------------------------ |
| `ai-agent-builder-mode`       | Build autonomous AI agents with tool use and reasoning |
| `langchain-llamaindex-mode`   | LangChain and LlamaIndex for RAG applications          |
| `llm-expert-mode`             | LLM integration, prompt engineering, and fine-tuning   |
| `mlops-expert-mode`           | ML pipelines, model deployment, and monitoring         |
| `rag-expert-mode`             | Retrieval-Augmented Generation architectures           |
| `vector-database-expert-mode` | Vector databases for embeddings and similarity search  |

## Usage

### AI Agent Builder Mode

Build intelligent agents with:

- Tool use and function calling
- Multi-step reasoning chains
- Memory and context management
- Agent orchestration patterns

### LangChain & LlamaIndex Mode

Framework expertise for:

- Document loaders and splitters
- Embedding pipelines
- Vector store integration
- Chain and agent construction

### LLM Expert Mode

Covers LLM development:

- API integration (OpenAI, Anthropic, etc.)
- Prompt engineering techniques
- Fine-tuning strategies
- Token optimization

### MLOps Expert Mode

Production ML operations:

- Model versioning and registry
- Feature stores
- A/B testing and canary deployments
- Model monitoring and drift detection

### RAG Expert Mode

Build RAG systems with:

- Chunking strategies
- Retrieval optimization
- Reranking techniques
- Hybrid search approaches

### Vector Database Mode

Vector storage expertise:

- Pinecone, Weaviate, Milvus, Qdrant
- Index optimization
- Similarity metrics
- Scaling strategies

## Recommended Workflow

1. **Design**: Start with `ai-agent-builder-mode` for architecture
2. **Build**: Use `langchain-llamaindex-mode` for implementation
3. **Optimize**: Apply `rag-expert-mode` for retrieval tuning
4. **Deploy**: Finish with `mlops-expert-mode` for production
