# Documentation Modes

Technical documentation and specification creation modes.

## Available Modes (1)

| Mode | Description |
|------|-------------|
| `create-prd-mode` | Product Requirements Document creation |

## Usage

### Create PRD Mode
Generates comprehensive PRDs including:
- Executive summary
- Problem statement
- Goals and objectives
- User stories
- Functional requirements
- Non-functional requirements
- Success metrics
- Timeline and milestones
- Risks and mitigations

## PRD Template Structure

```markdown
# Product Requirements Document

## 1. Executive Summary
Brief overview of the product/feature

## 2. Problem Statement
What problem are we solving?

## 3. Goals & Objectives
- Primary goals
- Success metrics

## 4. User Stories
As a [user], I want [goal] so that [benefit]

## 5. Requirements
### Functional Requirements
### Non-Functional Requirements
### Constraints

## 6. Out of Scope
What we're NOT building

## 7. Timeline
Milestones and deadlines

## 8. Risks & Mitigations
Potential issues and solutions
```

## Related Modes

For complete documentation workflow, combine with:
- `specification-mode` (Architecture) - Technical specs
- `documentation-generator-mode` (Output Formats) - Technical docs
- `planning-mode` (Planning) - Project planning
