# Testing Modes

Quality assurance and test automation modes.

## Available Modes (5)

| Mode | Description |
|------|-------------|
| `qa-automation-expert-mode` | Test automation frameworks and strategies |
| `test-automation-engineer-mode` | End-to-end test implementation |
| `accessibility-testing-mode` | WCAG compliance and accessibility testing |
| `performance-testing-mode` | Load testing, stress testing, and benchmarking |
| `qa-specialist-mode` | General QA methodologies and best practices |

## Usage

### QA Automation Expert Mode
Expertise in:
- Selenium, Playwright, Cypress
- Test framework design
- CI/CD integration
- Test data management
- Parallel test execution

### Test Automation Engineer Mode
Covers:
- Unit testing (Jest, pytest, JUnit)
- Integration testing
- E2E testing
- API testing (Postman, REST Assured)
- Mobile testing (Appium)

### Accessibility Testing Mode
Includes:
- WCAG 2.1 AA/AAA compliance
- Screen reader testing
- Keyboard navigation
- Color contrast analysis
- ARIA implementation
- Automated a11y tools (axe, WAVE)

### Performance Testing Mode
Focuses on:
- Load testing (k6, JMeter, Gatling)
- Stress testing
- Endurance testing
- Spike testing
- Metrics and KPIs
- APM integration

### QA Specialist Mode
Covers:
- Test planning and strategy
- Test case design
- Defect management
- Risk-based testing
- Exploratory testing
- Test reporting

## Testing Pyramid

```
        /\
       /  \      E2E Tests (few)
      /----\
     /      \    Integration Tests (some)
    /--------\
   /          \  Unit Tests (many)
  /------------\
```

Use these modes to implement comprehensive testing at all levels.
