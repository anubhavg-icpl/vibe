# Frameworks Modes

Modern web frameworks and full-stack development.

## Available Modes (9)

| Mode                     | Description                                       |
| ------------------------ | ------------------------------------------------- |
| `astro-expert-mode`      | Astro for content-focused static and hybrid sites |
| `fastapi-expert-mode`    | FastAPI for high-performance Python APIs          |
| `go-web-frameworks-mode` | Go web frameworks (Gin, Echo, Fiber, Chi)         |
| `nestjs-expert-mode`     | NestJS for enterprise Node.js applications        |
| `nuxt-expert-mode`       | Nuxt.js for Vue.js full-stack applications        |
| `phoenix-expert-mode`    | Phoenix framework for Elixir web development      |
| `remix-expert-mode`      | Remix for full-stack React applications           |
| `solidjs-expert-mode`    | SolidJS for reactive UI development               |
| `svelte-expert-mode`     | Svelte and SvelteKit for compiled web apps        |

## Usage

### Astro Expert Mode

Content-first framework:

- Island architecture
- Partial hydration
- Multi-framework support
- Content collections
- SSG and SSR

### FastAPI Expert Mode

Python API development:

- Async/await patterns
- Pydantic validation
- OpenAPI documentation
- Dependency injection
- Background tasks

### Go Web Frameworks Mode

Go backend development:

- Gin, Echo, Fiber, Chi comparison
- Middleware patterns
- Database integration
- Authentication
- Testing strategies

### NestJS Expert Mode

Enterprise Node.js:

- Modular architecture
- Dependency injection
- TypeORM integration
- GraphQL support
- Microservices

### Nuxt Expert Mode

Vue.js full-stack:

- File-based routing
- Auto imports
- Server routes
- Hybrid rendering
- Nuxt modules

### Phoenix Expert Mode

Elixir web development:

- LiveView for real-time UIs
- Channels for WebSockets
- Ecto for databases
- PubSub patterns
- Deployment

### Remix Expert Mode

React full-stack:

- Nested routing
- Data loading patterns
- Form handling
- Error boundaries
- Progressive enhancement

### SolidJS Expert Mode

Reactive UI framework:

- Fine-grained reactivity
- No virtual DOM
- Signals and stores
- SolidStart
- Performance optimization

### Svelte Expert Mode

Compiled framework:

- Component syntax
- Stores for state
- SvelteKit routing
- Server-side rendering
- Transitions and animations

## Recommended Workflow

1. **Choose Framework**: Match framework to project requirements
2. **Setup**: Initialize with best practices
3. **Build**: Follow framework patterns
4. **Deploy**: Use recommended hosting
