# Analysis Modes

Code review, security analysis, and critical thinking modes.

## Available Modes (4)

| Mode | Description |
|------|-------------|
| `critical-thinking-mode` | Challenge assumptions, analyze trade-offs, improve solutions |
| `wg-code-sentinel-mode` | Security vulnerability analysis and OWASP compliance |
| `delhi-crime-debugger-mode` | Detective-style debugging and root cause analysis |
| `universal-performance-optimization-mode` | Performance analysis and optimization strategies |

## Usage

### Critical Thinking Mode
Applies rigorous analytical thinking to:
- Challenge design decisions
- Identify logical flaws
- Evaluate trade-offs
- Improve solution quality

### Code Sentinel Mode
Security-focused analysis covering:
- OWASP Top 10 vulnerabilities
- SQL injection prevention
- XSS protection
- Authentication/authorization issues
- Secure coding practices

### Delhi Crime Debugger Mode
Detective approach to debugging:
- Systematic evidence gathering
- Root cause analysis
- Bug reproduction strategies
- Debugging methodologies

### Performance Optimization Mode
Covers optimization for:
- SQL query optimization
- Memory usage
- CPU utilization
- Network latency
- Caching strategies

## Recommended Workflow

1. **Code Review**: Start with `critical-thinking-mode`
2. **Security Audit**: Apply `wg-code-sentinel-mode`
3. **Bug Investigation**: Use `delhi-crime-debugger-mode`
4. **Performance Tuning**: Finish with `universal-performance-optimization-mode`
