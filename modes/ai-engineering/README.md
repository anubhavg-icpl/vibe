# AI Engineering Modes

Expert modes derived from the [AI Engineering from Scratch](https://github.com/rohitg00/ai-engineering-from-scratch) curriculum, a 20-phase, 260+ lesson course covering the full AI engineering stack from math foundations to production multi-agent systems.

Each mode embodies the persona of an expert in one phase of the curriculum.

## Modes

| Mode | Description |
|------|-------------|
| [setup-and-tooling-mode.md](./setup-and-tooling-mode.md) | Dev environments, Git, GPU, Docker, Jupyter, and Python tooling for AI work |
| [math-foundations-mode.md](./math-foundations-mode.md) | Linear algebra, calculus, probability, and optimization for ML, taught through code |
| [ml-fundamentals-mode.md](./ml-fundamentals-mode.md) | Classical ML algorithms, evaluation, feature engineering, and tabular pipelines |
| [deep-learning-core-mode.md](./deep-learning-core-mode.md) | Neural networks, backpropagation, optimizers, and a mini autograd from scratch |
| [computer-vision-mode.md](./computer-vision-mode.md) | CNNs, ViTs, detection, segmentation, diffusion, NeRF, and 3D vision |
| [nlp-foundations-to-advanced-mode.md](./nlp-foundations-to-advanced-mode.md) | Tokenization, embeddings, seq2seq, attention, retrieval, and LLM-era NLP |
| [speech-and-audio-mode.md](./speech-and-audio-mode.md) | Spectrograms, ASR, TTS, voice cloning, audio LMs, and real-time voice agents |
| [transformers-deep-dive-mode.md](./transformers-deep-dive-mode.md) | Self-attention, positional encoding, MoE, FlashAttention, and KV-cache from scratch |
| [generative-ai-mode.md](./generative-ai-mode.md) | VAEs, GANs, diffusion, flow matching, ControlNet, and LoRA across modalities |
| [reinforcement-learning-mode.md](./reinforcement-learning-mode.md) | MDPs, DQN, policy gradients, PPO, and RLHF for LLM alignment |
| [llms-from-scratch-mode.md](./llms-from-scratch-mode.md) | Tokenizers, pretraining, SFT, RLHF, DPO, quantization, and inference optimization |
| [llm-engineering-mode.md](./llm-engineering-mode.md) | Prompt engineering, structured outputs, RAG, function calling, evals, and MCP |
| [multimodal-ai-mode.md](./multimodal-ai-mode.md) | CLIP, LLaVA, Qwen-VL, Chameleon, omni-models, VLAs, and multimodal RAG |
| [tools-and-protocols-mode.md](./tools-and-protocols-mode.md) | Function calling, tool schemas, MCP servers and clients, A2A, and OTel GenAI |
| [agent-engineering-mode.md](./agent-engineering-mode.md) | Agent loops, planning, memory, reflection, frameworks, and eval-driven development |
| [autonomous-systems-mode.md](./autonomous-systems-mode.md) | Long-horizon agents, self-improvement, durable execution, and frontier safety |
| [multi-agent-and-swarms-mode.md](./multi-agent-and-swarms-mode.md) | Coordination patterns, communication protocols, MARL, and swarm optimization |
| [infrastructure-and-production-mode.md](./infrastructure-and-production-mode.md) | vLLM, SGLang, autoscaling, caching, observability, and FinOps for LLMs |
| [ethics-safety-alignment-mode.md](./ethics-safety-alignment-mode.md) | Alignment, red-teaming, jailbreak defense, fairness, privacy, and regulatory compliance |
| [capstone-projects-mode.md](./capstone-projects-mode.md) | Portfolio-grade end-to-end AI systems with eval, observability, and deployment |

## Source

These modes were derived from [rohitg00/ai-engineering-from-scratch](https://github.com/rohitg00/ai-engineering-from-scratch). Each mode summarizes one phase of that curriculum at expert-persona depth and is intended for use as a Claude Code mode within the vibe template.
