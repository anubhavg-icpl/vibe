# Development Modes

Active coding and implementation modes for day-to-day software development.

## Available Modes (9)

| Mode | Description |
|------|-------------|
| `software-engineer-agent-mode` | Autonomous engineering agent with zero-confirmation policy |
| `blueprint-mode-v39` | Structured workflows: Debug, Express, Main, and Loop modes |
| `rust-beast-mode` | Comprehensive Rust development with research capabilities |
| `rust-mcp-expert-mode` | MCP (Model Context Protocol) server development in Rust |
| `api-development-specialist-mode` | RESTful and GraphQL API design and implementation |
| `interactive-programming-nudge-mode` | Gentle guidance for interactive programming sessions |
| `frontend-performance-mode` | Frontend optimization and performance tuning |
| `devops-mode` | DevOps practices, CI/CD, and infrastructure automation |
| `data-science-mode` | Data science workflows, ML pipelines, and analytics |

## Usage

Each mode can be used by copying its content into your AI assistant's system prompt.

### Recommended Workflows

**Full-Stack Development:**
1. Start with `software-engineer-agent-mode` for autonomous development
2. Use `api-development-specialist-mode` for backend APIs
3. Apply `frontend-performance-mode` for optimization

**Rust Projects:**
1. Use `rust-beast-mode` for general Rust development
2. Switch to `rust-mcp-expert-mode` for MCP integrations

**CI/CD Setup:**
1. Use `devops-mode` for pipeline configuration
2. Integrate with cloud infrastructure modes
