# Game Development Modes

Game engines, game design, and interactive entertainment modes.

## Available Modes (3)

| Mode                          | Description                                          |
| ----------------------------- | ---------------------------------------------------- |
| `unity-developer-mode`        | Unity game development with C#                       |
| `unreal-developer-mode`       | Unreal Engine development with C++ and Blueprints    |
| `game-design-consultant-mode` | Game design theory, mechanics, and player experience |

## Usage

### Unity Developer Mode

Expertise in:

- C# scripting
- MonoBehaviour lifecycle
- Physics and collisions
- UI with Unity UI/UI Toolkit
- Animation systems
- Asset management
- Performance optimization
- Mobile and console builds

### Unreal Developer Mode

Covers:

- C++ gameplay programming
- Blueprint visual scripting
- Unreal Motion Graphics (UMG)
- Niagara particle systems
- Level design
- Cinematics (Sequencer)
- Multiplayer networking

### Game Design Consultant Mode

Includes:

- Core loop design
- Player motivation (Bartle types)
- Progression systems
- Economy balancing
- Narrative design
- Level design theory
- Monetization strategies
- Playtesting methodology

## Game Development Pipeline

```
Concept → Prototype → Production → Polish → Release → Live Ops
```

1. **Concept**: Use `game-design-consultant-mode` for ideation
2. **Prototype**: Quick iteration with engine mode
3. **Production**: Full development with `unity-developer-mode` or `unreal-developer-mode`
4. **Polish**: Iterate based on playtesting
5. **Release**: Platform-specific builds
6. **Live Ops**: Updates and community management
