# DevOps Modes

DevOps practices, SRE, and platform engineering expertise.

## Available Modes (7)

| Mode                        | Description                                             |
| --------------------------- | ------------------------------------------------------- |
| `aiops-expert-mode`         | AI-powered operations and anomaly detection             |
| `docker-expert-mode`        | Container building, optimization, and orchestration     |
| `finops-expert-mode`        | Cloud cost optimization and financial operations        |
| `gitops-expert-mode`        | Git-based infrastructure and deployment automation      |
| `incident-management-mode`  | Incident response, postmortems, and on-call practices   |
| `platform-engineering-mode` | Internal developer platforms and self-service tools     |
| `sre-expert-mode`           | Site reliability engineering and operational excellence |

## Usage

### AIOps Expert Mode

AI-driven operations:

- Anomaly detection
- Predictive alerting
- Root cause analysis
- Automated remediation

### Docker Expert Mode

Container expertise:

- Multi-stage builds
- Image optimization
- Docker Compose
- Security scanning

### FinOps Expert Mode

Cloud cost management:

- Cost allocation and tagging
- Reserved instance optimization
- Spot instance strategies
- Budget alerts and forecasting

### GitOps Expert Mode

Git-centric operations:

- Flux and ArgoCD
- Declarative infrastructure
- Drift detection
- Progressive delivery

### Incident Management Mode

Operational excellence:

- Incident classification
- Runbook automation
- Blameless postmortems
- On-call best practices

### Platform Engineering Mode

Developer experience:

- Internal developer portals
- Self-service infrastructure
- Golden paths
- Developer productivity metrics

### SRE Expert Mode

Reliability engineering:

- SLIs, SLOs, SLAs
- Error budgets
- Toil reduction
- Capacity planning

## Recommended Workflow

1. **Foundation**: Start with `docker-expert-mode` for containers
2. **Automation**: Apply `gitops-expert-mode` for deployments
3. **Operations**: Use `sre-expert-mode` for reliability
4. **Optimization**: Finish with `finops-expert-mode` for costs
